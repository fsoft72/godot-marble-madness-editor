# Changes

## 2026-11-01

- Added design document for the Godot port of marble-madness (`docs/superpowers/specs/2026-11-01-marble-madness-godot-port-design.md`).
- Added implementation plan for phases 1 and 2 (`docs/superpowers/plans/2026-11-01-marble-madness-godot-editor.md`).
- Added Godot project skeleton (`project.godot`, `.gitignore`), `Constants` class and a headless test runner (`tests/run_tests.gd`, `tests/test_case.gd`).
- Test runner now fails a test method that logs a runtime script error (Logger via OS.add_logger, `tests/error_capture.gd`).
- Added `BlockData`, `LevelData` and tolerant `LevelIO` (JSON load/save, snapshot/restore in place) with tests (`scripts/core/`, `tests/test_level_io.gd`).
- Added `History` undo/redo snapshot stacks (max 100 steps) with tests (`scripts/core/history.gd`, `tests/test_history.gd`).
- Added `BlockSurface` (port of `rotateUV` and `getBlockSurfaceY`), the golden data generator `tools/gen_golden.mjs` and `tests/golden/surface_y.json` (1725 entries) with tests (`scripts/geometry/block_surface.gd`, `tests/test_block_surface.gd`).
- Added `TextureFactory` (procedural top surface, cliff and flag materials, decals drawn with Image primitives, cached) with tests (`scripts/geometry/texture_factory.gd`, `tests/test_texture_factory.gd`).
- Added `BlockMeshBuilder` (port of `buildBlockMeshGroup`: top tiles with vertex shades, cliff walls with trim, stepped sub-tiles, cutouts, goal_bevel, Godot clockwise winding, named surfaces, collision faces derived from the same generated parts) with tests (`scripts/geometry/block_mesh_builder.gd`, `tests/test_block_mesh_builder.gd`).
- Added `ElementBuilder` (port of `buildElementOnBlock` and `createGuardTubeSegment`: guard tubes, cones with floor shadow, goal flags, glass marble start; visual only, block local coordinates) with tests (`scripts/geometry/element_builder.gd`, `tests/test_element_builder.gd`).
- Fixed `ElementBuilder` marbleColor parsing: accepts `#rrggbb` strings and ints, invalid values fall back to the default red.
- Added `LevelView` (one `Block_bx_bz` node per block with mesh, element and concave collider, per-block rebuild, physics-free `pick_cell` against cached faces, `cell_from_ground_ray`); void, absent and bare pit cells get no node (`scripts/editor/level_view.gd`, `tests/test_level_view.gd`).
- Added `CameraRig` (ortho arcade camera size 34 and perspective camera FOV 42, orbit/pan/zoom around a focus point with pitch clamp, arcade isometric reset around the `focus_on` point, `ray_from_screen`; right drag orbits, middle drag pans, wheel zooms) with tests (`scripts/editor/camera_rig.gd`, `tests/test_camera_rig.gd`).
- Added `EditorState` (tool, selection, brush, signals) and `Tools` (click tools SELECT/PAINT_BLOCK/PAINT_ELEMENT/PAINT_DECAL/ERASE/PICK with per-block view rebuild, keyboard `adjust_selected`: elevation 0.5, slope and tilt 0.2, rotate 90, delete; clicks outside the grid ignored with no snapshot) with tests (`scripts/editor/editor_state.gd`, `scripts/editor/tools.gd`, `tests/test_tools.gd`).
- `Tools.adjust_selected` now follows the JS key handler: creates the block on a selected empty cell, changes only the brush without a valid selection, and pushes a snapshot only when the level changes.
- Added the editor scene and UI: `EditorRoot` (owns level, history, state, view, camera rig and UI; left click picks a block then the ground plane and calls `Tools.apply`, paint and erase drags are one undo step, events over UI controls and typing in text fields are ignored, keys 1-5, W/S/A/D/Q/E/R/Del/Backspace, Ctrl+Z, Ctrl+Y, JS lights on a black background, hover and selection cursors) and `EditorUI` (top bar, palettes, inspector with sliders, rotation buttons and 3x3 sub-heights, coordinates badge, HUD hints, English texts behind one key helper). Grid, Clear, JSON, Level 1 and language buttons are present but disabled until their tasks. `scenes/editor.tscn` is the main scene (`scripts/editor/editor_root.gd`, `scripts/ui/editor_ui.gd`, `tests/test_editor_scene.gd`).
- Second click on the active palette item rotates the brush by 90 degrees (shape, element, decal).
- Editor fixes: drag strokes always keep one undo snapshot and end on tool change, undo or redo; undo and redo re-sync the inspector; sliders and spin boxes commit one snapshot per gesture and sliders ignore the wheel; a second palette click outside Select mode no longer edits the level; clicking the 3D view releases text focus.
- Added file IO, clear and grid toggle: `EditorRoot.load_level_from_text` (parse, snapshot, `copy_from` in place, so History and LevelView references stay valid; invalid input shows an error dialog and changes nothing), `load_level_from_file`, `save_level_to_file`, `clear_level` (one snapshot, none on an empty level), `toggle_grid`. Undo, redo, load and clear share `_after_level_replaced` (ends the stroke, drops an out-of-bounds selection, rebuilds view and grid, reframes on size change). New `GridLines` (port of the JS GridHelper, hidden by default, follows the level size). `EditorUI` gets open and save `FileDialog`s (`*.json`), an error `AcceptDialog` and enabled Grid, Clear, JSON open and JSON save buttons (`scripts/editor/grid_lines.gd`, `scripts/editor/editor_root.gd`, `scripts/ui/editor_ui.gd`, `tests/test_editor_scene.gd`).
- Added EN/IT translations: `I18n` (static table ported from the JS `I18N` table without emoji, `t`, `has`, `set_language` ignoring unsupported codes, `language`, `keys`; missing keys fall back to English then to the key, no engine error). Every UI string goes through it, including the coordinates badge (`Y` label), file dialog titles and filters, the error dialog and tool tooltips. The language button is enabled, cycles EN and IT, and `EditorUI.refresh_texts()` re-labels controls, inspector title, coordinates badge, HUD, dialogs and the open error. Renamed the key `export_json` to `open_json` (it opens a file; `save_json` saves). Default language is `en`, as in the JS editor (`scripts/ui/i18n.gd`, `scripts/ui/editor_ui.gd`, `tests/test_i18n.gd`, `tests/test_editor_scene.gd`).
- Added the Level 1 preset and reference overlay: `data/level01.json` (78 blocks, generated by `tools/gen_golden.mjs` from `createLevel01Preset()`, together with `tests/golden/level01_surface.json` holding the block count and 130 `surface_y` samples; the existing `surface_y.json` is unchanged), `EditorRoot.load_level01()` (same code path as loading JSON text: one undo step, error dialog on failure, camera reset to the arcade view), the enabled Level 1 button, and a hidden, half-transparent, mouse-transparent `TextureRect` overlay of `assets/level01_ref.png` toggled by a new Overlay button (EN/IT) (`scripts/editor/editor_root.gd`, `scripts/ui/editor_ui.gd`, `scripts/ui/i18n.gd`, `tests/test_level01.gd`).
- Fixed the arcade ortho size: the reset view now shows `34 / 0.88 = 38.6` units like the JS `camera.zoom = 0.88` (`scripts/editor/camera_rig.gd`).
- Fixed cones: the pyramid is now flat shaded like the JS `flatShading: true` (was smooth shaded, showing a gradient) (`scripts/geometry/element_builder.gd`).
- Final verification of phases 1 and 2: drove the real windowed app (real input events through the viewport, 70 checks: tools, keys, undo/redo, UI clicks, cameras, language, grid, overlay, Level 1, Clear, JSON save and open, invalid and web-format files) and ran the full test suite (143 passed). No defects fixed. Phase 3 (marble gameplay) gets its own design.
- Hardened `LevelData._normalize_block`: wrong-typed JSON values are coerced (`isVoid` to bool, `elevation`/`slope`/`tilt` to float, `shape`/`element`/`decal` to String, defaults when null or non-numeric), so hand-edited files no longer raise script errors; unknown keys are untouched (`scripts/core/level_data.gd`, `tests/test_level_io.gd`).
- Known open problems: the inspector corner inputs, diagonal split toggle and marble colour picker are not ported (Level 1 blocks using `vGrid`/`diagSplit` can only be erased, not edited); `data/level01.json` needs an `*.json` export include filter in exported builds, otherwise the Level 1 button shows the error dialog.
